## What it Adds ![flag-ui](https://cdn.modrinth.com/data/cached_images/07168fabc55b27c839020a72ea95f800af2b1964_0.webp)
- **Flags (Horizontal Banners)** &mdash; a new decorative block that mounts a banner sideways on a pole, with cloth that gently waves. Comes in **standing** and **wall-mounted** variants for all **16 dye colors**.
- **Full pattern support** &mdash; Flags use the vanilla banner pattern system, so every pattern, layer, and color you can put on a banner works on a Flag too.
- **Compatible with the banner system** &mdash; no new pattern items, no new mechanics to learn; if you know banners, you already know Flags.

## Craft From Your Banners ![flag-ui](https://cdn.modrinth.com/data/cached_images/07168fabc55b27c839020a72ea95f800af2b1964_0.webp)

Turn any banner into a Flag of the same color by crafting it with wool and a stick:

```
# # #      # = wool          (same color as the banner)
B # #      B = banner        (its base color drives the Flag)
S          S = stick
```

The Flag **keeps the banner's pattern** &mdash; craft a fully-decorated banner into a Flag and every layer comes along for the ride. Each color has its own recipe that unlocks just like vanilla banners: pick up (say) purple wool and the purple Flag recipe shows up in your recipe book.

> Flags also appear in the **Colored Blocks** and **Functional Blocks** creative tabs, right after the vanilla banners.
